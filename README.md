# Sai Thanmai Peddader Pally

**AI Engineer & Data Engineer** building agentic systems and production RAG pipelines that process millions of documents at scale.

Currently at Pycube, where I design AI agents and data infrastructure for hospital asset tracking across 22M+ medical documents. My work focuses on making LLMs actually useful in production: agents that reason over real data, retrieve the right information, and take action autonomously.

## What I build

**Agentic AI Systems**
I build multi-step AI agents using LangGraph and Claude that can classify intent, route to the right data source, retrieve context, and generate responses autonomously. My email classification agent handles 4 intent categories, queries MySQL and ChromaDB via MCP servers, and sends formatted replies through Outlook without human intervention.

**RAG & Search Pipelines**
I architect retrieval-augmented generation systems over large document stores using LangChain, FAISS, Pinecone, and ChromaDB. At Pycube, these pipelines achieve 92% retrieval accuracy across 22M+ medical documents, powering document Q&A for hospital clients.

**LLM Evaluation & Benchmarking**
I built evaluation frameworks that benchmark hallucination, coherence, and relevance across GPT, Claude, Mistral, and Llama. This reduced model failure rates by 30% across 8+ production AI projects.

**Data Infrastructure**
Real-time streaming with Kafka, Spark, and TimescaleDB. ML-based anomaly detection. Container orchestration. CI/CD pipelines on AWS.
